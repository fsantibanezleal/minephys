# Guides

> How to install and use `minephys`: in a notebook or pipeline, in the browser through Pyodide, and inside an NVIDIA Kit
> extension. · Part of: [docs home](../README.md) · Related: [reference](../reference/README.md)

**Status: filled in the build phase.**

Until the first release the library installs from its git repository:

```bash
uv add "minephys @ git+https://github.com/fsantibanezleal/minephys"
```

The guides will cover the PyPI install after the first release, loading the wheel in Pyodide, installing it into a
target folder for a Kit extension, reading a parameter with its citation, and citing the sources of the values used.
